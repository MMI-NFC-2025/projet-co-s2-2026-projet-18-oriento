- [ ] Description du projet : Oriento est une plateforme d'accompagnement administratif destinée aux étudiants français. Elle centralise toutes les démarches essentielles de la vie étudiante : études, logement, assurances en un seul endroit, avec des guides pas à pas, des ressources officielles, un suivi de progression personnalisé et un espace de stockage de documents administratifs. L'objectif est de simplifier et démystifier les démarches administratives pour les étudiants qui découvrent la vie autonome.
